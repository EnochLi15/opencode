# Agent 框架预研与洞察

**副标题：从框架能力到企业落地路线图**  
日期：2026-03-24  
产出方式：基于 OpenCode 工作流 + 联网资料研究

---

## 1. 概述：为什么 2026 年还要重做 Agent 技术选型

- **市场信号**：从“单轮问答”走向“可执行任务流”，Agent 已成为 AI 产品化核心层。
- **工程现实**：仅靠模型提示词无法保证可靠交付，必须引入状态机、工具治理、评测与可观测。
- **组织驱动**：企业希望把“人力流程”转化为“可追踪、可审计、可复用”的智能流程。
- **结论**：Agent 框架选择，本质上是“系统工程能力”选择，而不只是“模型接入 SDK”。

## 2. 主流框架对比（1/2）：定位与生态

| 框架 | 核心定位 | 优势 | 风险/短板 | 典型场景 |

## 3. 主流框架对比（2/2）：技术能力维度

评估维度建议（建议作为 PoC 打分卡）：

1. **编排模型**：Prompt 链 / 状态机 / DAG / 事件驱动
2. **工具接入**：函数工具、Web Search、File Search、MCP、内部 API
3. **状态管理**：短期会话状态 + 长期记忆 + 外部存储一致性
4. **可观测性**：轨迹、延迟、成本、失败路径、人工接管点
5. **评测体系**：任务完成率、事实准确率、工具调用成功率、人工返工率
6. **上线治理**：权限、审计、数据分级、失败降级与回滚

## 4. 核心技术架构：企业级 Agent 参考分层

```text
应用层（业务场景）
  └─ 客服/研发/销售/运营 Agent
编排层（Planner + Router + State Machine）
  └─ 任务分解、策略路由、重试与回退
能力层（Tools + Memory + Knowledge）
  └─ 内部 API、数据库、知识库、检索服务
模型层（多模型网关）
  └─ 推理模型、快模型、代码模型、视觉模型
治理层（Observability + Eval + Guardrail）
  └─ 监控、评测、安全策略、审计与合规
基础设施层
  └─ 队列、缓存、向量库、对象存储、CI/CD
```

---

## 5. 核心架构细化：关键设计决策

- **决策 1：以“状态机 + 工具契约”代替“纯提示词流程”**
  - 明确每一步输入/输出，降低幻觉导致的流程漂移。
- **决策 2：把“可恢复失败”作为一等能力**
  - 超时、权限、上游故障都应有自动重试、降级和人工接管。
- **决策 3：先定义评测，再扩展功能**
  - 每新增工具都要配套离线回放与线上 A/B 指标。
- **决策 4：多模型路由，不做单模型绑定**
  - 兼顾时延、成本和稳定性，避免被单供应商策略锁死。

## 6. 实践案例（案例 A）：研发效能 Agent（SDLC Copilot）

**目标**：将需求 -> 代码修改 -> 测试建议 -> 发布说明串成半自动链路。  

**实现要点**：
- 分工：Planner（拆任务）+ Coder（改代码）+ Reviewer（规范检查）+ Release（变更摘要）。
- 工具：代码检索、单测执行、静态检查、PR 模板生成。
- 治理：高风险文件变更强制人工确认。

**结果（PoC 可观测指标）**：
- 需求到可审阅 PR 时间缩短（目标：30%+）。
- 重复性修改自动化覆盖率提升（目标：40%+）。

## 7. 实践案例（案例 B）：企业知识服务 Agent

**目标**：将“政策/制度/产品文档”转化为可追溯问答与流程建议。  

**实现要点**：
- 检索增强：多路召回（向量 + 关键词 + 结构化库）。
- 可信输出：每条关键结论附来源段落与时间戳。
- 流程化：对“可执行请求”（如报销规则校验）走工具链而非自由生成。

**价值**：
- 降低一线支持负担；
- 统一答复口径；
- 强化合规留痕。

## 8. 最佳实践（Best Practices）

1. **从“高频、低风险、可量化”场景切入**，3~6 周验证 ROI。
2. **先工具后智能**：先把业务系统 API 契约化，再做复杂推理。
3. **每个 Agent 都要有“停止条件”与“接管条件”**。
4. **把失败样本做成持续评测集**，每周回归。
5. **建立成本驾驶舱**：按任务/团队/模型维度看 token 与时延。
6. **安全默认最小权限**：工具白名单 + 数据分级脱敏 + 审计日志。

## 9. 未来趋势分析（2026-2028）

- **趋势 1：Agent 从“对话体”走向“流程体”**
  - 更多采用图编排与事件驱动，减少不可控链式思考暴露。
- **趋势 2：评测与治理成为采购决策核心**
  - 框架差异将从“能不能做”转为“是否可审计、可运营”。
- **趋势 3：MCP/工具协议标准化加速**
  - 生态将围绕“可插拔工具层”形成竞争。
- **趋势 4：多 Agent 协作进入“人机共治”阶段**
  - 自动执行 + 人工审批混合成为企业默认模式。
- **趋势 5：行业 Agent 模板化**
  - 医疗、金融、制造等行业将出现可复用基线架构。

## 10. 落地路线图建议（90 天）

- **0-30 天**：选 2 个场景做并行 PoC，建立统一评测口径。
- **31-60 天**：接入核心业务工具链，打通日志与成本观测。
- **61-90 天**：上线灰度 + 人工接管流程，形成 Agent 运行手册。

**交付物**：
- 框架选型报告（含评分矩阵）
- 参考架构与治理规范
- 场景化模板（Prompt + Tool + Eval）
